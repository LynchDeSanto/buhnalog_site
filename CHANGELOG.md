### Изменено

#### Frontend
- **index.html**
  - Обновлён `<head>` с метатегами Open Graph и Twitter Cards
  - Добавлен favicon (SVG + fallback ICO)
  - Добавлена микроразметка Schema.org в JSON-LD формате
  - Добавлен виджет Cloudflare Turnstile в форму
  - Добавлен закомментированный код Яндекс.Метрики
  - Обновлён CSP для поддержки аналитики и CAPTCHA
  - Улучшен SEO-контент (дополнительные ключевые слова в hero-text)

- **script.js**
  - Добавлена поддержка Turnstile CAPTCHA (callback, валидация, сброс при ошибке)
  - Редирект на thank-you.html после успешной отправки (вместо сообщения на месте)
  - Отслеживание событий для Яндекс.Метрики (клики по телефону/email, использование калькулятора)
  - Флаг `turnstileEnabled` для включения/выключения CAPTCHA

- **styles.css**
  - Без изменений (все стили для новых страниц встроены inline)

#### Backend
- **server.js**
  - Добавлена функция `verifyTurnstile()` для проверки CAPTCHA-токена
  - Обновлён `handleApiSend()` с валидацией Turnstile
  - Извлечение IP-адреса клиента из заголовков (X-Forwarded-For, X-Real-IP)
  - Fail-open режим при недоступности Cloudflare

- **.env.example**
  - Добавлена переменная `TURNSTILE_SECRET_KEY`

### Требуется настройка

После клонирования проекта необходимо:

1. **Обязательно:**
   - Заполнить `.env` с токенами Telegram
   - Заменить тестовые контакты в HTML (телефон, email)
   - Заполнить ИНН, ОГРН, адрес в `privacy.html`
   - Создать OG-изображение `og-image.jpg` (1200×630px)

2. **Рекомендуется:**
   - Получить ключи Cloudflare Turnstile и включить CAPTCHA
   - Настроить Яндекс.Метрику и раскомментировать код счётчика
   - Настроить цели в Яндекс.Метрике для отслеживания конверсий

3. **Опционально:**
   - Настроить HTTPS через Let's Encrypt
   - Добавить rate limiting в nginx
   - Настроить мониторинг и логирование ошибок

Подробные инструкции: **[SETUP.md](./SETUP.md)**

## [1.0.0] - Исходная версия

### Возможности
- Адаптивный дизайн лендинга
- Интерактивный калькулятор услуг
- Форма обратной связи с отправкой в Telegram
- Node.js backend без внешних зависимостей

- Политика конфиденциальности (базовая версия)

- ❌ Нет защиты от спама
- ❌ Минимальные метатеги (только description)
- ❌ Нет аналитики

- ❌ Нет SEO-оптимизации (robots.txt, sitemap, микроразметка)
